# Keyboard shortcuts

Press `?` on any page to see the list over it, or open **Shortcuts** at the
bottom of the sidebar. Single keys work anywhere outside a text field, and not
while a menu or dialog is open.

## Anywhere

| Keys         | Action                                                                |
| ------------ | --------------------------------------------------------------------- |
| `/`          | Focus search                                                          |
| `c`          | Create issue                                                          |
| `g` then `d` | Go to the dashboard                                                   |
| `g` then `i` | Go to issues - the current project's, when you are in one             |
| `g` then `b` | Go to the board - the current project's, else the last one you opened |
| `g` then `m` | Go to my issues                                                       |
| `g` then `p` | Go to projects                                                        |
| `[`          | Collapse or expand the sidebar                                        |
| `?`          | Show keyboard shortcuts                                               |

After `g`, press the second key within a second.

## Search

| Keys  | Action                        |
| ----- | ----------------------------- |
| `Tab` | Complete the first suggestion |
| `↵`   | Run the query                 |

## Issue list

| Keys  | Action              |
| ----- | ------------------- |
| `Esc` | Clear the selection |

## Issue page

| Keys | Action                   |
| ---- | ------------------------ |
| `e`  | Edit the description     |
| `a`  | Open the assignee picker |
| `s`  | Open the status picker   |

## Knowledge base

| Keys          | Action                                                |
| ------------- | ----------------------------------------------------- |
| `e`           | Edit the article                                      |
| `Alt` `↑`/`↓` | Move the focused article in the tree among neighbours |
| `Alt` `→`     | Put it under the article above                        |
| `Alt` `←`     | Move it up a level                                    |

## Editor

| Keys             | Action             |
| ---------------- | ------------------ |
| `⌘ ↵` / `Ctrl ↵` | Submit the comment |

On the board and the backlog, cards and rows are dragged with the mouse, or with the
keyboard: focus a row's grip or a card, press `Space` to pick it up, move it with the
arrow keys, and `Space` again to drop it (`Esc` cancels).

Shortcuts for reports arrive with them.
